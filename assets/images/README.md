# Images Directory

## Profile Photo
Please add your profile photo as `profile.jpg` in this directory.

Recommended specifications:
- Format: JPG or PNG
- Dimensions: 300x300px minimum (square aspect ratio)
- File size: Under 500KB for optimal loading

The image will be displayed as a circular profile photo in the About section.
